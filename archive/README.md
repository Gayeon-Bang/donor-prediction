# archive

최종 분석 흐름에 들어가지 않은 초기 실험과 이전 버전 노트북입니다. 출력은 지웠습니다.

| 파일 | 내용 |
|---|---|
| early_* | 초기 데이터 결합(dataconcat)과 샘플 데이터 실험 |
| preprocessing_v1, label_encoding_variant | 전처리 초기 버전 (원-핫 vs 라벨 인코딩 비교) |
| modeling_v1, model_test_v2 | 모델링 초기 버전 |
| merged_data_check | 통합 데이터 점검 스크립트 |
| dropped_columns_memo | 제거 컬럼 검토 메모 |
| final_holdout_test | 80/20 홀드아웃 평가 (메모리 부족으로 미완료) |
