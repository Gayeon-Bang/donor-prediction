# 연도별 변수 통일 규칙

사회조사는 연도마다 문항과 선택지 코드가 조금씩 다릅니다. 5개년(2015~2023) 데이터를 합치기 전에 정리한 규칙입니다. 실제 코드는 [02_merge_and_standardize](../notebooks/02_merge_and_standardize.ipynb)에 있고, 연도별 컬럼 대응표는 [column_map_by_year.xlsx](column_map_by_year.xlsx)에 있습니다.

## 타깃

| 변수 | 규칙 |
|---|---|
| 기부여부 | 2015년은 1·2·3(기부 유형별 응답) → 1(기부), 4 → 2(비기부)로 통합. 이후 모델링에서 1→0, 2→1로 바꿔 "비기부"가 양성 클래스 |

## 선택지 코드 재매핑

| 변수 | 대상 연도 | 규칙 |
|---|---|---|
| 재학상태코드 | 2015·2017·2019 | 2와 3을 서로 바꿈 |
| 혼인상태코드 | 2019·2021·2023 | 5 → 2로 통합 (4개 범주로 축소) |
| 혼인상태코드 | 2017 | 3 → 1, 4 → 3, 5 → 4, 6 → 5 |
| 향후추가대상복지서비스_1~3순위 | 2021·2023 | 10개 선택지 → 2019 이전의 8개 기준으로 재매핑 |
| 우선실시장애인복지사업_1~3순위 | 2021·2023 | 11개 선택지 → 9개로 재매핑 |
| 노후준비방법 (주된·부수적) | 2021·2023 | 4 → 9로 옮긴 뒤 5~9를 하나씩 당김 |
| 노후희망활동 | 2023 | 1순위만 사용, 7·8 통합, 2 → 1 통합 후 재인덱싱 |
| 노후희망활동 | 2021 | 1·2 통합 후 재인덱싱 |
| 가구소득코드 | 2017~2023 | 8과 9를 합쳐 2015년 기준(8)으로 맞춤 |

## 형식이 다른 문항

| 변수 | 규칙 |
|---|---|
| 참여단체_1~3순위코드 (2015·2017) | 2019년 이후 형식에 맞춰 단체 유형 9개(친목사교, 종교, 취미·스포츠, 시민사회, 학술, 이익, 정치, 지역사회, 기타)별 0/1 더미로 변환 |
| 신문 구독 여부 (2015) | 1~4 → 1(구독), 5 → 2(미구독) |
| 혼인신고여부, 사회보험료 부담 인식, 장애인 유대관계 대상 | 해당 연도에 없는 경우 결측을 0(해당 없음)으로 채움 |

## 제외한 변수

- 일부 연도에만 있는 문항: 활동제약 상세, 코로나 관련 문항, 장애인 견해, 표본층번호 등
- 기부 경험을 전제로 묻는 세부 문항: 기부 내용·주기·사유·인지경로, 정기기부 세부 항목
- 자원봉사 분야별 횟수·시간 (연도별 분류 체계가 달라 통일 불가)
- 근로여건 세부 만족도 (2015년에 없고 결측이 많아, 전반적 일자리 만족도로 대체)
